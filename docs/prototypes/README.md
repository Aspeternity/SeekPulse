# SeekPulse — Web-first Stage A 产品原型

> 本目录是 **可在浏览器离线打开的产品交互草案**，不是运行中的 SeekPulse，也不是可部署生产 Web。  
> 对应 Issue [#59](https://github.com/Aspeternity/SeekPulse/issues/59)、独立分支 `design/web-first-stage-a-prototype`。用户已明确批准 Web-first 产品方向和 A→E 开发顺序；**Stage A 的 UI 尚待人工验收，B 阶段实际后端改造不在此 PR 内。**

## 打开方式

1. 下载同目录 `seekpulse-web-first.html` 文件；用 Chrome / Edge / Firefox 打开即可（不需要 Docker、Node/npm、Python、外部 CSS/CDN 或网络）。
2. 默认显示**五步首次设置向导**，可逐步前进，也可跳过并直接浏览页面。
3. 体验六个页面：**运行概览、监控来源、关键词规则、通知管理、推送历史、系统设置**。
4. 建议尝试：切换 RSS 与 TG 来源、模拟授权、创建/编辑/启停关键词、配置 Telegram Bot、添加 Bark/ntfy 目标、模拟测试与默认路由、深色模式，以及窄屏手机布局。
5. **请勿输入真实 Token、密码、手机号、Session 或设备 Key**。此 HTML 只有静态内容与页面内存中的模拟状态，**不运行任何请求、不持久化凭据或状态**；刷新即重置。

## 确定的产品边界（UI 设计基线）

- **Portainer + Compose** 只负责镜像、宿主端口、持久化数据目录和必要运行限制；使用 Web 完成管理员创建、来源/通知/规则等日常配置。
- Web **先于可选采集/通知组件可用**；单个来源未配置、授权失效或某个通知平台故障，不能阻断整个 Web 管理中心。
- Web **本地管理员**独立于 Telegram 用户与 Bot；TG 发送 Bot、TG 频道监听 Telethon 是不同组件。
- RSS/TG 来源独立启停、状态清晰可见；“配置完毕”与“运行中/连接正常”不是同一个状态。
- **Telegram Bot、Bark、ntfy 的真实配置入口在 Web**，不是“环境变量引用”；UI 应支持目标新增、编辑、测试、暂停、删除及默认/规则级路由。
- 继续保留已经验证的帖子标准化、可靠去重、投递队列、恢复和源补查的业务接口；在 B 及后续阶段审查必要重构，不在 A 阶段触碰。
- Web 数据管理应包含备份/校验/恢复说明；默认不挂载 Docker Socket，也不把未经验证的公网开放当作方便访问。

## 原型覆盖

| 页面 / 流程 | A 阶段可点击内容 | 实际能力 |
|---|---|---|
| 五步安装向导 | Web 管理员 → Bot → 来源 → 通知 → 完成 | 纯演示，未创建账号/数据库 |
| 概览 | 运行模块示意、配置提示、来源状态 | 无真实后端数据 |
| 监控来源 | RSS 间隔/启停、TG 授权流程按钮和状态 | 没有真实 RSS/TG 请求 |
| 关键词规则 | 新增/编辑/暂停/删除、优先级、目标路由、屏蔽词 | 只改当前页面内存 |
| 通知管理 | Telegram Bot、Bark、ntfy 配置表单、目标与默认路由、模拟测试 | 不保存密钥、不发送真实消息 |
| 推送历史 | 按状态筛选、查看模拟错误详情 | 虚构示例数据 |
| 系统设置 | 管理员、参数、备份、诊断、主题演示 | 不访问 SQLite、宿主机或 Portainer |

## 离线人工/自动验收

- 在本地 Chromium/Playwright 内用同一 HTML 测试了首装五步、六个页面、关键词添加/编辑、Bark/ntfy/Telegram Bot 表单、未授权 TG 开关阻断、RSS 间隔、通知模拟测试、明暗模式、手机导航。
- **该次本地测试：PASS；JavaScript pageerror 0、外部 HTTP 请求 0**。这仅证明 UI 交互模型可以运行，**不是**正式浏览器全兼容测试，也不是 CI 或产品实机验收。
- A 阶段需用户实际浏览反馈并明确验收。**未经单独授权，不合并 main、不开始 B 阶段、更不发布 RC2 或修改 NAS/PVE。**

## 后续（待分阶段授权）

B：最小 Portainer Compose/Web-first 服务、独立管理员与首次初始化；C：TG/Bark/ntfy 实际 Web 配置与运行动态生效；D：规则/历史/诊断/备份整合；E：真实 Portainer 端到端、恢复升级、稳定性、安全回归、发布审批。
