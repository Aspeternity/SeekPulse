# ADR-0003：GitHub 为事实来源、单任务单写入负责人

- 状态：已批准（G0 实施范围）
- 日期：2026-10-13

## 背景

ChatGPT、Claude、Gemini 多 AI 轮换与长对话中断容易导致重复开发、过时 CI、遗漏验收及未经授权合并。

## 决定

- 统一 `AGENTS.md`，其他代理文件只指向该文件。
- 产品范围由审批文档证明，代码和 CI 由具体 GitHub SHA 证明，验收由用户证据证明。
- 一个 Issue、一个写入负责人、独立分支和 PR；AI 接管前先核对分支、关联 Issue、HEAD SHA 及剩余事项。
- 交接脚本只读汇总实时远端，离线和不可访问明确标记 `UNKNOWN`。
- 不因 CI 通过自动合并、发布、部署；每阶段用户验收后才能申请下一授权。

## 禁止

自动分配/接管他人的工作分支、凭旧对话自行改代码、混淆 CI 与实机验收、未获批准修改 main/生产环境。
